# ROADMAP

This roadmap is closed.

LW2B is **archived** and the demo is **complete**.

## Final snapshot

LW2B reached a compact but meaningful endpoint:
- core RTS loop implemented
- deterministic simulation foundation in place
- wood economy and opening-plan gameplay added
- movement and worker recovery passes landed
- offline simulation mode available
- online runtime supports `peerjs`, `ws-relay`, and `mwc` in code
- AI behavior expanded well beyond basic sparring support

The project is no longer in active expansion.

## Why the roadmap is closed

The project reached the point where the next meaningful step would no longer be a narrow continuation pass.

A substantial further increase in gameplay variety would require a broader content/design phase, likely involving more unit-role diversity, wider strategic vocabulary, and deeper map-mechanical differentiation.

That is a different scope from the demo/research phase that LW2B successfully completed.

## Final priorities that were completed or resolved enough for closure

1. Establish a credible deterministic RTS gameplay loop.
2. Improve movement, worker recovery, and simulation stability.
3. Build a meaningful AI validation surface beyond minimal opponent behavior.
4. Support multiple online transport paths without rewriting the gameplay model.
5. Normalize documentation so the project can be understood after active work stops.

## What is not an active next step anymore

The following should not be read as live roadmap tracks anymore:
- ongoing gameplay tuning as a continuing production plan
- active AI expansion as a standing workstream
- broad online/runtime evolution as an active milestone ladder
- further architectural growth by default

These may still be interesting areas of study, but they are not the current plan.

## If revisited later

Any future return should begin with a fresh decision:

### Option A
Preserve LW2B as a small polished demo/reference project.

### Option B
Treat the next phase as a larger game-design/content expansion with a new scope baseline.

That future work should be framed as a new phase, not as simple continuation of this closed roadmap.
